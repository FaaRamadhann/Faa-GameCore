WHY FGC

Kontrol yang terasa,
tanpa drama.

Satu modul untuk menjaga sesi game tetap bersih, dengan guard dan recovery di setiap langkah.

◎

Freeze reversibel

App di-disable hanya selama sesi dan dikembalikan saat sesi selesai.

⌁

Whitelist menang

App yang kamu lindungi dan yang sudah disabled sendiri tidak disentuh.

▣

WebUI jelas

Kelola game, list, profile, log, dan diagnostics dari satu interface.

↻

Anti-nyangkut

Supervisor, journal, dan recovery menjaga core tetap pulih setelah crash.

HOW IT WORKS

Simple di permukaan.
Serius di bawahnya.

01

Detect

Foreground game dideteksi dari capability device.

02

Protect

Whitelist dan policy menyaring target sebelum tindakan.

03

Clean up

Target dibersihkan sesuai profile lalu dikembalikan.

GET STARTED

Install dalam beberapa menit.

Download ZIP, install lewat manager root, reboot, lalu buka WebUI dan pilih game.

su -c 'fgc status'
su -c 'fgc add blacklist com.example.app'
su -c 'fgc set default_profile 3'
